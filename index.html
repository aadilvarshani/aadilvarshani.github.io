Building the sensor

ReaperWatch, open source

So I built the last seat myself. ReaperWatch is a Windows EDR: a C++ agent on ETW that enriches every process launch, and a Node.js console that runs it through an EQL rule engine. Four releases in, kernel driver next.

  2. Enrichlineage, hashes, signer
